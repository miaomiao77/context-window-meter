# 2.1.0 手动扫描设计与阶段检查点

2026-10-20，用户授权实现手动扫描并要求中途保存。基线 2.0.2 / 05c85b3。已从远程恢复源代码，主分支不改。

目标：手动逐页读取当前会话、按 ID 去重、进度与取消、诚实报告完整度；不声称剩余容量，不新增持久聊天/统计存储。

## 关键决定
- 主动请求必须由隔离世界 UI 的真实点击发起；MAIN 消息桥没有启动扫描命令。
- 隔离世界通过同源 /api/auth/session 临时取得 accessToken，仅用于固定同源历史 GET；禁止重定向、不记录/桥接/持久化令牌，不读取账号字段。需要在隐私说明明确，这是相对 2.0.2 的新行为。
- 从复数详情开始，沿 page_info.start_cursor 调用 /messages，串行、间隔、可取消，有页数/字节/时长上限。不自动重试 401/403/429，不主动刷新登录，不改会话。
- 去重仅保存内存中的消息 ID、统计摘要和文本摘要哈希；不缓存整段正文。跨页重叠须顺序相容且摘要一致；游标不前进、重复页、结构错误均停止并保留部分统计。
- 分页数组没有 parent 链，读到 has_previous_page=false 只说明接口历史读完。只有服务端提供可核对的 mapping 父链、根与目标叶节点时，才报告分支已验证；不得用数组顺序伪造证明。扫描尾部再取首页核对分支与内容未变。
- 导航、发送、分支操作或读数失效时取消/废弃扫描；结果为某一时刻快照，后续发送需重新扫描。
- Chat/Work 模式保持分开，未知模式不自行判定为 Chat。
